# Database Systems

## Overview

Database Systems coursework focused on designing and analysing a relational database system using Entity Relationship Diagrams (ERD), entities, relationships and database modelling principles.

## Key Areas

* Evaluated and improved an existing Enhanced Entity Relationship Diagram (EERD)
* Identified entities, attributes and relationships
* Designed relationships using multiplicities and cardinalities
* Applied primary key and foreign key concepts
* Used specialisation to represent different entity types
* Developed a logical ERD based on a given business scenario
* Considered data integrity and relationship structure

## Database Design

The coursework involved modelling a racket sports management system, including entities such as:

* Player
* Booking
* Court
* Park
* Instructor
* Session
* Equipment
* Caretaker
* Maintenance Log
* Block Booking
